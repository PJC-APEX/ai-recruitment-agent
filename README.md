# AI Recruitment Agent

An intelligent recruitment assistant that leverages LangGraph's agentic workflows and RAG (Retrieval-Augmented Generation) to help recruiters search, evaluate, and compare candidate resumes.

## Key Features
- 🤖 **AI Agent Architecture**: LangGraph-powered workflow for multi-step reasoning
- 🔍 **Semantic Search**: ChromaDB vector store with Azure OpenAI embeddings
- 💬 **Conversational Interface**: Natural language queries for candidate search
- 📊 **Smart Ranking**: Automated candidate scoring and comparison
- 🎯 **Context-Aware**: RAG pipeline for accurate resume information retrieval

## Tech Stack
- **Backend**: FastAPI, Python 3.12
- **AI/ML**: LangGraph, LangChain, Azure OpenAI (GPT-4.1)
- **Vector DB**: ChromaDB
- **Frontend**: React, Vite, TailwindCSS
- **Resume Parsing**: PyMuPDF, custom chunking strategies
